# data/ — the archive as pipeline input

`fragments.jsonl` is generated by [scripts/convert_archive.py](../scripts/convert_archive.py) from `writing_machines.xlsx` (the original class export, kept at the repo root). Don't edit it by hand; fix the spreadsheet or the script and regenerate.

One JSON object per line, one line per fragment (161 lines). Each fragment is one retrieval chunk; none is long enough to need splitting.

| Field | Meaning |
| --- | --- |
| `id` | The website's "Fragment No." (1–161, no gaps). The chatbot cites this. |
| `archive_id` | The archive's permanent entry ID (the spreadsheet `id` column; has gaps where entries were deleted). |
| `entrant` | Contributor name. Used by `--entrant`. |
| `category` | The archive's constellation, e.g. "Geometry". |
| `text` | `fragment` + blank line + `Annotation: ` + `annotation`. **This is what gets embedded.** |
| `fragment` | The quotation if `is_quote` is true; otherwise a paraphrase, the student's own claim, or a placeholder (e.g. #51 is an image label with no image). |
| `annotation` | The student's commentary. |
| `source`, `source_url` | Bibliographic info; either may be null. |
| `is_quote` | Whether `fragment` is a direct quotation. |

Site number = rank by `archive_id`, because the site counts entries in the order added and skips deleted ones.
